# 开源项目周榜 Top 10

每周用中文整理 GitHub Trending 全语言周榜前十，帮助快速了解热门项目的用途和上手方式。

- **榜单来源**：[GitHub Trending · This week](https://github.com/trending?since=weekly)
- **更新计划**：每周日 19:00，北京时间（Asia/Shanghai）。
- **历史归档**：[查看每期周榜](reports/README.md)
- **每期内容**：排名、项目链接、中文简介、主要用途、编程语言、本周新增星标、总星标、许可证状态和官方上手文档。

## 排名与数据口径

保持抓取时 GitHub Trending 页面的前十顺序，不按总星标或本周新增星标重新排序。每期记录实际抓取时间；榜单会随时间变化。

只记录经来源核实的数据。缺失字段标注“未提供”或“待核实”；公开源码不等同于具有开源许可证，许可证不明确时单独说明。来源不可用时不以历史缓存充当当期榜单。

## 更新方式

由已配置的 Codex 每周任务整理并提交到本仓库的 `main` 分支。每期文件保存在 `reports/YYYY-MM-DD.md`，索引保存在 `reports/README.md`。保留历期记录，同一天重复执行时先核实已有内容，避免重复提交。

目前采用桌面端定时任务，执行时需保持电脑和 Codex 应用运行。本仓库收录项目资料及官方入口；具体安装和运行可在选定项目后另行安排。
