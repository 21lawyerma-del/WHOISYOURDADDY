## 项目简介与上手入口

### 1. REA

把 AI 助手连接到本地分析工具，调查应用功能、JavaScript/Electron 程序、原生二进制等，并给出分析依据。适合软件研究和需要理解程序行为的开发者。

**上手**：先阅读[安装与配置指南](https://github.com/morluto/rea/blob/main/docs/installation.md)。README 提供 Node.js/npm 安装入口；原生分析还需要相应分析引擎。

来源：[README](https://github.com/morluto/rea/blob/main/README.md) · [MIT 许可证](https://github.com/morluto/rea/blob/main/LICENSE)。

### 2. ArtCraft

面向设计师和影视创作者的图像、视频创作环境。可以先安排二维图层或三维场景，再控制构图、角色姿态和相机位置，迭代生成结果。

**上手**：从 README 指向的[官方下载入口](https://getartcraft.com/)了解应用，开发者可参考[源码构建说明](https://github.com/storytold/artcraft/blob/main/_docs/dev_setup.md)。

来源：[README](https://github.com/storytold/artcraft/blob/main/README.md) · [MIT](https://github.com/storytold/artcraft/blob/main/LICENSE-MIT) · [Apache-2.0](https://github.com/storytold/artcraft/blob/main/LICENSE-APACHE)。项目使用双许可证；第三方材料另见仓库 NOTICE。

### 3. AnyPS5

通过重新链接可执行文件和实现系统库来推进跨平台移植。项目仍维护兼容性进展和未完成部分，不能据此假定任意游戏都可直接运行。

**上手**：阅读[使用说明](https://github.com/boykopovar/AnyPS5/blob/main/docs/user/USAGE.md)并核对具体程序的兼容性；自行构建参照[构建文档](https://github.com/boykopovar/AnyPS5/blob/main/docs/dev/BUILD.md)。

来源：[README](https://github.com/boykopovar/AnyPS5/blob/main/README.md) · [许可证](https://github.com/boykopovar/AnyPS5/blob/main/LICENSE)。

### 4. Claude Code Plugins Directory

由 Anthropic 管理的插件目录，包含内部维护的插件及合作方、社区提供的插件。可作为发现 Claude Code 扩展功能的入口。

**上手**：在 Claude Code 的插件发现界面查找目标插件，按[README 安装说明](https://github.com/anthropics/claude-plugins-official/blob/main/README.md#installation)安装具体插件，并阅读该插件自身的说明。

来源：[README](https://github.com/anthropics/claude-plugins-official/blob/main/README.md) · [仓库许可证](https://github.com/anthropics/claude-plugins-official/blob/main/LICENSE)。外部插件及依赖可能适用不同条款。

### 5. Context Mode

通过在工具侧处理大段输出、保存和检索会话事件，减少原始数据进入 AI 上下文的数量。适合频繁读取日志、文件和工具结果的编程工作流。

**上手**：按所使用的平台阅读[安装章节](https://github.com/mksglu/context-mode/blob/main/README.md#install)。各平台的 MCP、hooks 和路由配置不同，不能共用一套配置。

来源：[README](https://github.com/mksglu/context-mode/blob/main/README.md) · [Elastic License 2.0](https://github.com/mksglu/context-mode/blob/main/LICENSE)。许可证文本包含向第三方提供托管服务等限制，因此这里标为“源码可见、带限制”，不笼统归入宽松开源许可。

### 6. Diagram Design

给 AI 助手使用的图解技能，输出可独立打开的 HTML + SVG 文件。适合架构图、流程图、时序图及演示中的说明图，也支持按品牌风格调整。

**上手**：查看[安装说明](https://github.com/cathrynlavery/diagram-design/blob/main/README.md#install)和官方示例，再选择自己的 AI 工具对应的安装方式。

来源：[README](https://github.com/cathrynlavery/diagram-design/blob/main/README.md) · [MIT 许可证](https://github.com/cathrynlavery/diagram-design/blob/main/LICENSE)。

### 7. Ghidra

软件逆向分析工具集，提供反汇编、反编译、图形分析及脚本扩展，支持多种处理器指令集和可执行格式。

**上手**：从[README 安装章节](https://github.com/NationalSecurityAgency/ghidra/blob/master/README.md#install)核对 Java 版本要求，下载官方发行包，再按说明启动。源码压缩包与可直接使用的发行包是不同下载项。

来源：[README](https://github.com/NationalSecurityAgency/ghidra/blob/master/README.md) · [Apache-2.0 许可证](https://github.com/NationalSecurityAgency/ghidra/blob/master/LICENSE)。

### 8. HyperFrames

将 HTML、CSS、媒体素材和可定位时间的动画渲染为 MP4 视频。既能通过本地命令行使用，也提供 AI 编程助手可用的技能。

**上手**：参考 README 链接的[官方快速入门](https://hyperframes.heygen.com/quickstart)，从一个短视频示例开始，完成预览和渲染流程。

来源：[README](https://github.com/heygen-com/hyperframes/blob/main/README.md) · [Apache-2.0 许可证](https://github.com/heygen-com/hyperframes/blob/main/LICENSE)。

### 9. Cursor Plugins

Cursor 的官方插件集合和规范示例，覆盖开发工具、协作服务和工作流。每个插件目录包含自己的描述文件。

**上手**：先看[仓库 README 的插件列表](https://github.com/cursor/plugins/blob/main/README.md)，进入所需插件目录阅读配置和使用说明。

许可证核对：README 的 License 章节写明 MIT；本次根目录文件列表没有独立 LICENSE 文件，GitHub 元数据也未识别统一许可证。应继续核对选中插件的具体许可文件。

### 10. AI Job Search

基于 Claude Code 的求职工作流，用于建立个人资料、评估岗位匹配、调整简历、撰写求职信和准备面试。其职位搜索入口较偏向丹麦市场，其他地区需要替换相应来源。

**上手**：阅读[设置指南](https://github.com/MadsLorentzen/ai-job-search/blob/master/SETUP.md)并核对所需工具。README 明确提醒，个人求职资料应放在自己的私有副本中，避免提交到公开仓库。

来源：[README](https://github.com/MadsLorentzen/ai-job-search/blob/master/README.md) · [MIT 许可证](https://github.com/MadsLorentzen/ai-job-search/blob/master/LICENSE)。
